# mitoLocalSources
Computing concentrations of material in mitochondrial networks with local injection sites.

To use this package, clone the repository and open the "hopping_sites_math_demo.m script in matlab. You will also need to clone https://github.com/lenafabr/networktools and add NetworkObj.m to your path. Running the demo script will generate 2 figures showing (1) a summary of important network connectivity statistics and (2) the mean and variance of the steady-state concentration of material in the network as predicted by our mathematical model.
